<h2>Development</h2>

```bash
bun install
bun run dev     # janux dev
bun run build   # RSS + janux build (output: static → dist/client)
bun test src    # unit tests
```

The whole site is prerendered (`output: 'static'`): every page ships as plain
HTML with zero blocking JavaScript, and the blog search / theme picker resume
as Janux islands on interaction. `sitemap.xml`, `robots.txt` and the `.md`
projection of every page are generated by the build.
